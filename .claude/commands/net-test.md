# /net-test

**Phase:** 4 (meta) — test plan + targeted test authoring
**Owning agent:** `.claude/agents/dotnet-test-engineer.md`
**Skills used:** `dotnet-testing-patterns`, `requirements-traceability`, `dotnet-coverage-and-mutation`, `dotnet-architecture-rules`

## Purpose
Author or extend `06-test-plan.md` and add tests that close coverage or mutation gaps without doing production work.

## Inputs
- `<feature-id>` (positional). Required.
- `--gap` (optional; reads the latest `artifacts/harness-summary.json` and targets uncovered lines / surviving mutants).

## Reads
- `.specs/<feature-id>/01-spec.md`, `.specs/<feature-id>/03-design.md`, `.specs/<feature-id>/04-tasks.md`
- `artifacts/harness-summary.json`, `artifacts/coverage/cobertura.xml`, `artifacts/new-code-coverage.json`, `artifacts/stryker/` (if present)
- `.claude/templates/test-plan.template.md`

## Writes
- `.specs/<feature-id>/06-test-plan.md`
- `.specs/<feature-id>/07a-traceability.md` (regenerated by the traceability script)
- New or extended files under `tests/<Module>.Tests/**` and `tests/<Module>.IntegrationTests/**` only. Never modifies `src/<Module>/**`.

## Process
1. Build/refresh `06-test-plan.md`: matrix of AC × test scope (unit, slice via `WebApplicationFactory`, integration via Testcontainers, contract, mutation-targeted), plus the container requirements per integration suite.
2. Add the cross-cutting suites the design calls for: ArchUnitNET rules (slice and module boundaries, no EF Core types on the API surface, no ambient time, no cycles), a Verify-approved snapshot of the generated `artifacts/openapi/openapi.json`, an integration smoke test, and property-based tests where the logic is amenable.
3. If `--gap` was passed, read `artifacts/harness-summary.json` plus `artifacts/coverage/cobertura.xml` and the Stryker.NET report; list uncovered lines and surviving mutants as `Gap-NNN` with proposed tests. A `skipped` mutation gate (no `stryker-config.json`) is not a gap.
4. Write the proposed tests with the attribute block in order: `[Fact]`/`[Theory]` → `[Trait("AC", "AC-NNN")]` → `[Trait("Category", "Integration")]` for anything needing a container or the full host. Assertions use Shouldly; doubles use NSubstitute; time comes from `TimeProvider`/`FakeTimeProvider`.
5. Run `dotnet test --filter "Category!=Integration"`, and `dotnet test --filter "Category=Integration"` if integration tests changed. Quote the result tail.
6. Update the traceability matrix by running `./.github/scripts/traceability-dotnet.sh <feature-id>`.

## Refuse if
- Asked to modify any file under `src/<Module>/**` (delegate to `/net-build`).
- The active feature has no `04-tasks.md`.
- A test would need `[Fact(Skip="...")]` with no reason naming an issue or ADR, or would weaken an existing assertion (`forbid-skip-flags.sh` also blocks skip flags on the test invocation).
- A proposed test is tautological — it only asserts a speculative method returns a fixed value. Raise a `Q-NNN` design gap instead.

## Done when
- `06-test-plan.md` is up to date and every AC has at least one planned test.
- Any `Gap-NNN` items have either a closing test or an explicit `Won't fix` rationale.
- Every newly authored or modified test carries `[Trait("AC", "AC-NNN")]`, and every integration test also carries `[Trait("Category", "Integration")]`.
- The traceability matrix is regenerated via `./.github/scripts/traceability-dotnet.sh <feature-id>`.
